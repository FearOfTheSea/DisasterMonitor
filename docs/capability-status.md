# Capability and promotion status

This page is the release-evidence authority. Code availability, automated tests, and
normative promotion are separate claims.

- **Implemented**: a bounded production path exists with stated authority and fallback.
- **Automated passing**: repository fixtures and fault injections pass; this is not
  evidence of external validity or human utility.
- **Promotion passed**: the declared external or human evidence exists and passed.
- **Promotion pending**: required evidence is absent; repository fixtures cannot replace it.
- **Unsupported**: no production path is claimed.

Volcanic-eruption discovery is implemented as a bounded primary Smithsonian/GVP path;
its preliminary WVAR coverage and source limitations remain explicit and do not imply
complete global surveillance or impact evidence.

## Evidence rules

Pending promotion requires locked provenance, checksums, rights, study-local identities,
and the evaluator named by the relevant family. Synthetic data, LLM judges, simulated
participants, and repository-authored labels do not satisfy external or human gates.
Missing benchmark, licensing, ethics, participant, pilot, or recovery evidence fails
closed. Until promotion, the bounded implementation and its fallback remain active.

Incident Watch v1 is implemented and automatically tested for deterministic change
classification, idempotency, queue retry, in-memory/PostgreSQL persistence, HTTP
contracts, and in-app timeline behavior. This demonstrates the bounded local mechanism,
not provider completeness, timely global detection, alert usefulness, or operational
response outcomes. Those claims remain promotion-pending and require locked live
episodes plus supervised human evaluation.

Run the relevant evaluator from the repository root:

```powershell
uv run --directory apps/api pytest -q tests/evaluation
```

Multimodal preparation and operator-study commands are documented in
[multimodal-awareness.md](multimodal-awareness.md).

## Unsupported

Automatic imagery retrieval, live weather, geocoding, arbitrary source crawling,
automatic source trust promotion, hosted models, production authentication/TLS,
multi-user persistence, cloud deployment, public warnings, evacuation directives, and
resource orders remain unsupported. Email, SMS, browser/OS push, and externally routed
Incident Watch notifications are also unsupported.
