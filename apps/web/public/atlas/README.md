# Local atlas data

Natural Earth vector data, 1:110m and 1:50m scales, downloaded from
https://github.com/nvkelso/natural-earth-vector at revision
`ca96624a56bd078437bca8184e78163e5039ad19` on 2026-09-24.

Files:

- `ne_110m_admin_0_countries.geojson`: generalized land and country boundaries.
- `ne_50m_admin_0_countries.geojson`: country boundaries at detailed zoom.
- `ne_110m_geography_marine_polys.geojson`: ocean labels.

Natural Earth data is public domain. Terms: https://www.naturalearthdata.com/about/terms-of-use/
This basemap is generalized reference geography, not event evidence or a source of
impact boundaries.
